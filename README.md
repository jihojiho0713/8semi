## 4. 공정별 미니게임

| 공정 | 미니게임 |
| --- | --- |
| 웨이퍼 제조 (Wafer Fabrication) | 회전하는 다이아몬드 톱날으로 잉곳을 정확한 두께(㎛ 단위)로 썰어내는 슬라이스 게임 |
| 산화 공정 (Oxidation) | 흐르는 가스(산소/수증기)의 양에 맞춰 리듬에 맞게 버튼을 눌러 웨이퍼 위에 균일한 두께의 산화막을 쌓아 올리는 게임 |
| 포토 공정 (Photolithography) | 웨이퍼를 고속으로 회전시키면서 중앙에 감광액(PR)을 떨어뜨려, 원심력으로 표면에 얇고 균일하게 펴 바르는 타이밍/드래그 게임 |
| 식각 공정 (Etching) | 화학 용액 수조에 웨이퍼를 담갔다가 정확한 타이밍에 건져내는 게임. 너무 오래 담그면 회로가 과도하게 깎이고(Over-etch), 적게 담기면 덜 깎임(Under-etch) |
| 증착 및 이온주입 공정 (Deposition & Ion Implantation) | 떨어지는 원자 블록(CVD 가스 분자)을 빈틈없이 겹겹이 쌓아 올려 표면에 빈 공간(Void) 없이 완벽한 박막 층을 완성하는 테트리스 변형 게임 |
| 금속 배선 공정 (Metal Interconnection) | 트랜지스터와 전원을 연결하기 위해 끊어져 있는 금속 배선 타일을 회전시켜 전류가 통하는 완벽한 길을 만들어내는 배관공(Pipe) 스타일의 퍼즐 게임 |
| EDS 공정 (Electrical Die Sorting) | 웨이퍼의 여러 다이(Die)들 중에 아주 짧은 시간 동안 켜지는 X 표시를 클릭해 없애는 게임 |
| 패키징 공정 (Packaging) | 레이저나 블레이드를 이용해 격자무늬(Scribe line)를 따라 웨이퍼를 손상 없이 낱개의 칩(Die)으로 정밀하게 잘라내는 선 긋기/자르기 게임 |
