## 4. 공정별 미니게임

| 공정 | 미니게임 | 조작 |
| --- | --- | --- |
| 1. 웨이퍼 제조 (Wafer Fabrication) | 잉곳 위를 좌우로 왕복하는 다이아몬드 톱날이 초록색 규격 구간에 들어온 순간 잘라내는 타이밍 게임. 웨이퍼 5장을 규격 두께(725㎛)로 썰면 성공 | 절단 버튼 / 스페이스바 |
| 2. 산화 공정 (Oxidation) | 계속 흔들리는 산소·수증기 목표 농도를 +/− 버튼으로 따라가는 밸런싱 게임. **두 가스가 동시에** 목표 구간에 있을 때만 산화막 두께 게이지가 차오름 | 산소 +/−, 수증기 +/− 버튼 / 방향키 |
| 3. 포토 공정 (Photolithography) | 회전 버튼을 연타해 웨이퍼 RPM을 적정 구간(2200~3400)까지 올린 뒤, 감광액 스포이드를 드래그해 정중앙에서 떨어뜨리는 게임. 너무 느리면 뭉치고 빠르면 날아감 | 연타 + 드래그 |
| 4. 식각 공정 (Etching) | 버튼을 꾹 누르면 웨이퍼가 에천트 용액에 잠기며 깊이가 깊어짐. 목표 구간에서 손을 떼야 성공. 넘기면 Over-etch, 모자라면 Under-etch. 3회 성공 | 길게 누르기 |
| 5. 증착 및 이온주입 공정 (Deposition & Ion Implantation) | 원자 블록이 하나씩 내려오는 테트리스 변형. 맨 아래 3층을 빈칸 없이 채우면 성공. 아래를 비워둔 채 쌓으면 Void(공극)로 카운트 | A/D·방향키 또는 화면 버튼 |
| 6. 금속 배선 공정 (Metal Interconnection) | 4×4 배선 타일을 눌러 90도씩 돌려 왼쪽 전원(⚡)부터 오른쪽 트랜지스터(TR)까지 잇는 배관공 퍼즐. 전류가 닿은 배선은 실시간으로 점등 | 타일 클릭 |
| 7. EDS 공정 (Electrical Die Sorting) | 원형 웨이퍼의 다이 격자에서 잠깐 켜지는 불량 신호 ✕를 꺼지기 전에 눌러 잉크 마킹하는 두더지잡기. 30초 안에 12개 | 다이 클릭 |
| 8. 패키징 공정 (Packaging) | 다이 사이 스크라이브 라인 통로를 따라 레이저를 드래그해 완주하는 정밀 조작 게임. 다이에 닿으면 칩이 깨져 그 줄은 처음부터. 4줄 완주 | 드래그 |

미니게임은 모두 순수 JavaScript로 구현했고 외부 라이브러리를 쓰지 않는다. 마우스와 터치를 모두 지원하며, 375px 폭에서도 가로 스크롤 없이 동작한다.
